# Phase 18: Example Apps

## Goal

Build a small set of example app ideas and use the easiest one as a real harness trial.

## Candidate Apps

- [x] CLI todo app with JSON persistence and native tests.
- [x] Markdown blog generator with static HTML output.
- [x] Express notes API with HTTP tests.
- [x] CSV expense analyzer with grouped reports.
- [x] SQLite habit tracker with migrations.
- [x] Local Markdown search app with a ranking dependency.
- [x] React Kanban board with browser-facing UI.

## Selected App

The CLI todo app is the first example because it is deterministic, small, and still exercises multi-file generation, persistence, argument parsing, and tests.

## Done Criteria

- [x] Add an example app catalog.
- [x] Generate the CLI todo app through Kodr.
- [x] Apply the generated app into `examples/todo-cli`.
- [x] Run the example app tests.
- [x] Update Kodr if the trial exposes a harness gap.
- [x] Document the result in the matching blog post.
