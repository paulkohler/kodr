# Phase 69: Self-Dev: Plan-Then-Execute Run

## Goal

Validate the 58–68 arc end-to-end by running Kodr against a real multi-step task
with the local model: write a plan to the scratchpad, then execute it across
turns using the inspector tools, producing a real multi-file patch.

This is the acceptance test for the whole inspection + self-healing arc, and it
enforces the AGENTS.md rule that examples must be generated by Kodr itself
against the local model — never by a frontier model.

## Design

Add a `64-prompt.md` describing a multi-step task. Run Kodr (local qwen model)
so it:

- writes a plan to the scratchpad on the first turn
- uses `inspect_symbols` / `find_references` to navigate
- carries the scratchpad across at least two turns
- produces a multi-file patch

Mirror the structure of the Phase 54–56 self-dev phases. Diagnose harness vs.
example issues before any hand-editing, and document hand-edits in
`process/failures.jsonl`.

## Non-Goals

- No frontier-model generation of the example.
- No new harness features — this phase exercises existing ones.

## Done Criteria

- [ ] A recorded, model-generated self-dev run artifact exists.
- [ ] The run uses inspector tools and carries scratchpad across ≥2 turns.
- [ ] Failures documented in `process/failures.jsonl`.
- [ ] Blog post capturing harness gaps found.
- [ ] Mark roadmap complete and commit.
