Create an Express.js API backed by Postgres for a small team documents service.

Use the guidance in AGENTS.md. Build the app in this directory with Node.js 24
ESM, Express, pg, Docker Compose, SQL migrations, native node:test tests,
README instructions, and .env.example.

The API should implement users, user settings, documents, document versions, and
document tags. Keep the code dependency-light and readable. Do not add a UI.
