## Phase Contract

Each phase is complete only when:

- Tests pass.
- The phase file has checked done criteria.
- `process/decisions.jsonl` or `process/failures.jsonl` has relevant entries.
- The matching blog post exists or is updated.
- A commit captures the phase.
